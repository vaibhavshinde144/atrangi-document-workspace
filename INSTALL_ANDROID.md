# Install Atrangi Document Workspace on Android

## Download APK from GitHub Actions
1. Open the repository.
2. Select **Actions**.
3. Open **Build Android APK**.
4. Open the latest successful run.
5. Download the **Atrangi-Document-Workspace-Android** artifact.
6. Extract the downloaded ZIP.
7. Copy `app-debug.apk` to your Android phone.
8. Open the APK and allow **Install unknown apps** for your browser or file manager when Android asks.
9. Install and launch **Atrangi Document Workspace**.

The testing APK is debug-signed. A Play Store or production release requires a private release signing key.
