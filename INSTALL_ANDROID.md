# Install Atrangi Document Workspace on Android

## Install the latest APK

1. On Android, open `https://vaibhavshinde144.github.io/atrangi-document-workspace/downloads/Atrangi-Document-Workspace.apk`.
2. Allow **Install unknown apps** for the browser or file manager if Android asks.
3. Install the update over the existing Atrangi app, then launch it.

The app continues to receive hosted workspace updates automatically. Android requires user confirmation when a new APK changes native code or launcher resources.

The testing APK is debug-signed. A Play Store or production release requires a private release signing key.
